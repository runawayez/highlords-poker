# Internationalization

Catalogs live at `apps/web/src/i18n/locales/{pt-BR,en}/{common,lobby,game,chat,profile,errors}.json`. Tournament strings use the game namespace because they share table vocabulary. Both catalogs must contain identical keys and interpolation parameters; automated tests enforce this and static `t()` references.

The header has a globe + named native select; it is keyboard accessible, displays its current option, and can add languages without a binary toggle. Language changes update `<html lang>`, preserve room identity/current hand and persist locally. The first visit always uses Portuguese (Brazil), regardless of browser language. An explicit saved language choice is restored on subsequent visits. No translation service/network API is used.

System messages persist as stable codes and parameters; each browser translates them. Chat/user names/room names remain original text. Card ranks, brand names, UUIDs and command enum identifiers are stable. Use Intl for numbers, dates and times. Add new text to both catalogs in the same change.

The profile/preference schema is versioned, local and separate from the anonymous credential key. Import allowlists preference fields and rejects invalid icons/colors/themes or oversized files. Export omits credentials and local achievement IDs.
